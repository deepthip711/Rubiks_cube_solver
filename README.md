# Rubik's Cube Visual Solver

A simple interactive Rubik’s Cube visualizer and step-by-step solver built with HTML, CSS, and JavaScript.

## 🔧 Features

- Rotate individual cube faces (U, D, F, B, L, R)
- Scramble the cube with random moves
- Step-by-step solve (reverse scramble)
- 2D cube net layout with real-time updates

## 📁 How to Run

1. Clone or download the repo
2. Open `index.html` in any browser
